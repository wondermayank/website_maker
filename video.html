Faceless Shorts Skill

A free Claude skill that makes narrated faceless Shorts for you.

How to install
  1. Unzip it and put the faceless-shorts folder in ~/.claude/skills/.
  2. Run bash scripts/setup.sh until it prints “All set” (or just ask Claude to set it up).
  3. Start a new Claude Code session and ask: “Make a Deep Dive 3D short: what happens if you crack your knuckles?”

Needs Claude Code (or Claude linked to your computer), Node.js 22+, ffmpeg, Chrome and Python 3.10+. Claude installs anything missing.

AI Video Editor Skill

A free skill that edits your talking-head videos: it cuts the silences and mistakes, then adds motion graphics.

How to install
  1. Install ffmpeg and Python 3.9+ if you don’t have them.
  2. Unzip it and put the ai-video-editor folder in ~/.claude/skills/ (OpenCode reads the same folder).
  3. Start Claude Code or OpenCode and say: “Edit my video” followed by the path to your video file.

The first time, it runs a one-time setup that installs the free tools it needs. Works with 16:9 videos for now.

Thunder Hand Drawing

Explainer and study videos on any topic: Tiny teaches while pen drawings draw themselves on notebook paper or paint in as watercolor.

How to install
  1. Download the .skill file. It is a zip, so unzip it into ~/.claude/skills/ (or upload it in Claude’s Skills settings).
  2. Start a new Claude session and describe the video you want. Claude asks which design to use before it builds anything.
  3. Claude sets up a ready Remotion project, writes the storyboard, makes the voice and renders an MP4.

Needs Node 18+, Python 3 and ffmpeg. Voices are free (Edge voices, Hindi and English). Claude installs anything missing. Designs: Hand-drawn, Watercolor, Sketch + wash.

Clone any style

Found a look you love? Send Claude a screenshot and it rebuilds that look as a new animated style, sound included.

  1. Pick a starting style. Choose the one closest to the look you want.
  2. Copy the prompt and paste it into a new Claude chat.
  3. Attach 1 to 3 screenshots of the style you want, then send.

Claude first explains how the animation engine works, then shows you a test frame of your style, and only builds the full video after you say OK.
