© 2026 FlatlyMade with care
Key traits
  • Solid colour fills, no gradients
  • No drop shadows or bevels
  • Simple geometric icons
  • Bold, readable sans-serif
Best for

Marketing sites, mobile apps, dashboards and anything that must load fast.

Fonts to tryInter, Poppins, Roboto
How to design it
  1. Pick one strong brand colour and 2 to 3 bright supporting colours.
  2. Fill every shape with a solid colour. Skip shadows, gradients and textures.
  3. Separate areas with colour blocks, not borders or shadows.
  4. Use simple geometric icons with the same stroke or fill style.
  5. Show hover and focus with a colour change, so users still know what is clickable.
Colour palette
Blue#2563ebYellow#fde047Mint#bbf7d0Coral#fecacaInk#1f2937
Do
  • Keep contrast high between text and fill
  • Use a small, consistent colour set
  • Make hover and focus states obvious
Don’t
  • Add soft shadows or gradients
  • Use thin low-contrast outlines only
  • Mix many unrelated colours
CSS recipe
:root{--blue:#2563eb;--ink:#1f2937}
.card{background:#fde68a;border-radius:6px}
.btn{background:var(--blue);color:#fff;border:0;border-radius:6px;padding:11px 20px}
.btn:hover{background:#1d4ed8}
/* no box-shadow, no gradients */

© 2026 Studio NMade with care
Key traits
  • Generous whitespace
  • Large, light typography
  • One accent or none
  • Hairline rules instead of boxes
Best for

Portfolios, editorial sites, luxury and product pages.

Fonts to tryInter Light, Helvetica Neue, DM Sans
How to design it
  1. List what the page must do, then delete everything else.
  2. Use a 2-colour palette, usually black on white, with at most one accent.
  3. Set a big heading, a small body and lots of margin around both.
  4. Use hairlines and spacing, not boxes, to group content.
  5. Keep one clear primary action per screen.
Colour palette
White#ffffffInk#111111Grey#777777Line#e5e5e5Accent#111111
Do
  • Let whitespace create the grouping
  • Keep copy short and clear
  • Stick to one typeface family
Don’t
  • Fill empty space just because it is empty
  • Use more than one accent colour
  • Hide the main action in clutter
CSS recipe
body{background:#fff;color:#111;font:300 16px/1.7 Inter,sans-serif}
h1{font-size:clamp(34px,8vw,64px);font-weight:300;letter-spacing:-2px}
.section{padding:96px 32px}
.card{border-top:1px solid #111;padding-top:20px}
.btn{background:#111;color:#fff;border-radius:0;padding:12px 22px}

Key traits
  • Background blur on panels
  • Semi-transparent white fill
  • Thin light border
  • Vivid colour behind the glass
Best for

Dashboards, music and weather apps, OS-style panels and hero sections.

Fonts to tryInter, SF Pro, Manrope
How to design it
  1. Start with a vivid gradient or colourful shapes behind the UI. Glass needs something to blur.
  2. Give panels a white fill at 10 to 20 percent opacity.
  3. Add backdrop-filter: blur(12px to 20px).
  4. Add a 1px light border and a soft shadow to define the edge.
  5. Use white text and check contrast against the busiest part of the background.
Colour palette
Indigo#4f46e5Magenta#c026d3Orange#f97316Glassrgba(255,255,255,.16)Edgergba(255,255,255,.4)
Do
  • Test text contrast on the busiest area
  • Keep only a few glass layers
  • Provide a solid fallback without blur
Don’t
  • Stack many blurred layers (slow on phones)
  • Use glass on a flat plain background
  • Put small grey text on glass
CSS recipe
.glass{background:rgba(255,255,255,.16);
  -webkit-backdrop-filter:blur(16px);backdrop-filter:blur(16px);
  border:1px solid rgba(255,255,255,.4);

© 2026 Soft UIMade with care
Key traits
  • Background and element share one colour
  • Light shadow top-left, dark shadow bottom-right
  • Raised for buttons, inset for inputs
  • Low contrast, so use sparingly
Best for

Smart-home controls, calculators, music players and small widgets.

Fonts to tryPoppins, Nunito, Inter
How to design it
  1. Pick a mid-light base colour such as #e0e5ec and use it for page and elements.
  2. Add two shadows: a dark one bottom-right and a white one top-left.
  3. Use raised for buttons and cards, inset shadows for inputs and pressed states.
  4. Round the corners generously (14 to 24px).
  5. Add a coloured icon or label so each control is still readable.
Colour palette
Base#e0e5ecDark shadow#a3b1c6Light shadow#ffffffText#3d4468Accent#6c7bff
Do
  • Use it for a few key controls
  • Add colour to icons and labels
  • Show a clear pressed state
Don’t
  • Use it for a whole content-heavy site
  • Rely on shadows alone for contrast
  • Forget keyboard focus rings
CSS recipe
.neu{background:#e0e5ec;border-radius:24px;
  box-shadow:9px 9px 18px #a3b1c6,-9px -9px 18px #fff}
.neu-in{box-shadow:inset 5px 5px 10px #a3b1c6,inset -5px -5px 10px #fff}
.neu-btn:active{box-shadow:inset 5px 5px 10px #a3b1c6,inset -5px -5px 10px #fff}

© 2026 BentoMade with care
Key traits
  • Grid of rounded cards
  • Mixed spans: 1x1, 2x1, 2x2
  • Even gaps (12 to 16px)
  • One idea per card
Best for

Product pages, dashboards, feature overviews and portfolios.

Fonts to tryInter, SF Pro, Geist
How to design it
  1. Plan a 4-column grid with equal gaps of 12 to 16px.
  2. Give the most important card the biggest span, usually 2x2.
  3. Use equal rounded corners (20 to 28px) on every card.
  4. Vary card colours softly so the grid has rhythm.
  5. Collapse to 2 columns, then 1, on small screens.
Colour palette
Page#f5f5f7Card#ffffffDark card#111111Sky#e0e7ffMint#dcfce7
Do
  • Keep gaps and radii identical
  • Put the key card top-left, biggest
  • Keep each card to one message
Don’t
  • Mix many corner radii
  • Put long text in small cards
  • Leave uneven holes in the grid
CSS recipe
.bento{display:grid;grid-template-columns:repeat(4,1fr);
  grid-auto-rows:120px;gap:14px}
.bento .big{grid-column:span 2;grid-row:span 2}
.bento .wide{grid-column:span 2}
.bento>*{border-radius:26px;padding:20px;overflow:hidden}
@media(max-width:600px){.bento{grid-template-columns:repeat(2,1fr)}}

Key traits
  • 3px black borders

Best for

Fonts to trySpace Grotesk, Archivo Black, DM Mono
How to design it
  1. Use a cream or white page with pure black text and borders.

  3. Fill boxes with bright flat colours: yellow, pink, lime, sky.
  4. Use heavy grotesque type, often uppercase for headings.

  • Mix in soft gradients

Key traits
  • Dark grey, not pure black
  • Light text with high contrast
  • Desaturated accent colours
  • Borders and elevation by lightness
Best for

Developer tools, media apps, dashboards, night-time reading and gaming.

Fonts to tryInter, JetBrains Mono, IBM Plex Sans
How to design it
  1. Start from dark grey (#0f1115) instead of pure black.
  2. Raise surfaces with lighter greys, not shadows.
  3. Use off-white text (#e8eaed) and keep contrast above 4.5:1.
  4. Use one softer, lighter accent such as #8ab4ff.
  5. Offer a toggle and respect prefers-color-scheme.
Colour palette
Background#0f1115Surface#171a21Border#262b36Text#e8eaedAccent#8ab4ff
Do
  • Use dark grey rather than #000
  • Lower the saturation of accents
  • Check contrast on every surface
Don’t
  • Use pure white text on pure black
  • Use fully saturated neon colours
  • Forget images and charts need dark variants
CSS recipe
:root{color-scheme:dark}
body{background:#0f1115;color:#e8eaed}
.card{background:#171a21;border:1px solid #262b36;border-radius:14px}
.btn{background:#8ab4ff;color:#0b1020}
@media(prefers-color-scheme:dark){/* auto dark */}
